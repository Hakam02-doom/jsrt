What the host does

Everything that matters is ours

Budgets that name who stopped it. CPU, memory and wall-clock, per worker.

jsrt supervise looper.js --wall-ms 400
looper.jsburning wall clocksupervisorSIGTERM at 400 msreportexit 6 · wall-clock
0100200300400 ms
{"outcome":"terminated","exit_code":6, …
 "killed_by":"wall-clock","signal":15}

One JSON line per run. killed_by names the budget, or operator-sigterm.

--wall-ms
a deadline for the whole run
--max-rss-mb
memory footprint, polled
--max-cpu
CPU seconds, via RLIMIT_CPU
--kill-grace-ms
SIGTERM to SIGKILL, 500 ms default

Secrets stay out of the logs. Redaction on forwarded output.

$ jsrt supervise leaker.js --redact-env SECRET_VALUE

the token is hunter2[redacted]

Forwarded by the supervisor

Terminal escapes neutralised

One namespace. rt.* and nothing else.

  • rt.fetchHTTP, to declared hosts only
  • rt.readTextfiles inside the declared paths
  • rt.kvan embedded SQLite store
  • rt.servea loopback HTTP listener
  • rt.mediacontent-addressed uploads

V8 inside, Rust in charge. Every op checks the grant.

  1. await rt.fetch(url)your script, in V8
  2. op_fetcha Rust function
  3. manifest.net?granted: the request goes outrefused: CapabilityError
